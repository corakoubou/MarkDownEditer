図・要素の編集

図のメモ（選択中の図）

図ごとに保存されます。Mermaid上には表示されません。JSON保存には含めません。

要素をクリックしてください。

矢印を選択すると「＋ 活性化」「－ 終了」を設定できます。縦線上に実行中の太い帯を表示し、Mermaidにも + / - を出力します。

線の既定値

方向ごとの既定線種はブラウザに保存されます。

テンプレート（選択中の図のみ）

登録・適用ともに選択中の1図だけが対象です。既存の全図テンプレートは先頭の図を読み込みます。

Markdown / Mermaid

選択中の図 — 編集・反映

選択中の図だけを置換します。## / ### などの見出しがあれば図の名前も更新します。他の図は変更しません。

すべての図 — 出力専用

全図のMarkdownをまとめて確認できます。この欄から図への反映は行いません。

関数の自動登録一覧

関数を選ぶと、呼び出し先と戻りまでの処理をシーケンス図で表示します。

参加者管理 — 全図共通の一括編集

同じ物理名と表示名の組み合わせをまとめて表示します。変更は「全図に反映」を押したときに一括適用されます。図ごとの個別編集も引き続き使用できます。

参加者の照合確認

Markdownの参加者に対し、既存の参加者を採用するか、新規作成するかを選んでください。確定するまで図は変更されません。

設定

クラス図

クラス図の設定は変更すると自動保存されます。既存のメンバーは削除しません。

図の編集・操作 — ショートカット

Ctrl・Shift・Altのいずれかを選び、キー欄をクリックして使いたいキーを押してください。空欄は未設定です。
シーケンス図でのみ有効です。文字入力中・ダイアログ表示中には実行しません。ブラウザーやOSが優先する組み合わせは使用できない場合があります。

URL設計

シーケンス図の右向き関数から [メソッド]URL を自動取得します。同じメソッド・URLは1行にまとめます。編集内容は自動保存されます。

機能名HttpメソッドURLパラメーター形式同期・非同期通信関数上の表記

「関数上の表記」を入力すると、対応するURLをクラス図へ関数として取り込む際の名前になります。同期を外したクラス図の関数名は保持します。シーケンス図から参照がなくなった行も、設計内容の保護のため保持します。
