Sequence Visual Editor v3.6
線を引くモードで参加者間をドラッグ。制御枠は右下の黄色い点でサイズ変更できます。

図・要素の編集

要素をクリックしてください。

矢印を選択すると「＋ 活性化」「－ 終了」を設定できます。縦線上に実行中の太い帯を表示し、Mermaidにも + / - を出力します。

線の既定値

方向ごとの既定線種はブラウザに保存されます。

関数の自動登録

矢印の受信者と名前から「受信者:矢印名」を関数キーとして扱います。呼び出しから呼び出し元への戻り矢印までを関数本体として検出し、別の図でも展開します。戻りがなければ末尾までを登録します。範囲内のノート・制御枠も含めて再利用します。

テンプレート

Markdown / Mermaid

「コードを反映」は現在の図の矢印・Note・制御枠だけを更新します。図のタイトルや参加者は変更・追加しません。Mermaidには制御枠の座標・寸法がないため、編集用JSONで寸法を保持します。
