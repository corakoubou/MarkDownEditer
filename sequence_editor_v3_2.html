全体操作
画面切替
図の選択
図の編集・操作ノート・制御枠は右下の黄色い点でサイズ変更できます。

図・要素の編集

要素をクリックしてください。

矢印を選択すると「＋ 活性化」「－ 終了」を設定できます。縦線上に実行中の太い帯を表示し、Mermaidにも + / - を出力します。

線の既定値

方向ごとの既定線種はブラウザに保存されます。

テンプレート（選択中の図のみ）

登録・適用ともに選択中の1図だけが対象です。既存の全図テンプレートは先頭の図を読み込みます。

Markdown / Mermaid

選択中の図 — 編集・反映

選択中の図だけを置換します。## / ### などの見出しがあれば図の名前も更新します。他の図は変更しません。

すべての図 — 出力専用

全図のMarkdownをまとめて確認できます。この欄から図への反映は行いません。

関数の自動登録一覧

関数を選ぶと、呼び出し先と戻りまでの処理をシーケンス図で表示します。

参加者管理 — 全図共通の一括編集

同じ物理名と表示名の組み合わせをまとめて表示します。変更は「全図に反映」を押したときに一括適用されます。図ごとの個別編集も引き続き使用できます。

参加者の照合確認

Markdownの参加者に対し、既存の参加者を採用するか、新規作成するかを選んでください。確定するまで図は変更されません。
